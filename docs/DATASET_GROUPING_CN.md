# 图片分组（手动划分 Train / Val）

UI：「图片分组」标签页。代码：`ui/dataset_grouping_page.py` + `core/manual_dataset_split.py`。
测试：`tests/test_manual_dataset_split.py`。

## 它解决什么问题

自动划分（`docs/DATASET_AUTO_SPLIT_CN.md`）按比例随机切分，不知道哪些照片拍的是同一个
书架。同一场景的照片被切到 train 和 val 两边时，验证指标会偏乐观——模型在 val 上见到的
是它训练时几乎见过的画面。这一页让人按图片决定归属，并给每张图打一个**场景组**标签。

**源数据永不修改**，导出总是写到一个新目录。

## 使用流程

1. **加载**：填服务器路径，每行一个，可分批追加。
   - 指向标准数据集目录时，只读取 `train/val/test` 下的 `annotations.json`，
     旁边的备份目录（例如 `test.pre_0725_merge_20260725/`）会被忽略。
   - 指向其他目录时递归查找 COCO；也可以直接指定单个 COCO 文件。
   - 已在 `train/val/test` 子目录下的图片会**继承原有分组**，其中 **test 会被锁定**，
     之后不能移动到 train/val，也不能通过恢复名单改变身份。
2. **浏览**：每页 24 张，带标注轮廓预览（多边形画轮廓，RLE 画外接框）。
   可按文件名 / 路径 / 场景组筛选。
3. **分配**：勾选本页图片 → 可选填场景组名 → 选择 train / val / 待分配 → 应用。
   **筛选或翻页会清空勾选**，跨页操作前先应用当前页。
4. **导出**：填一个**不存在**的新目录 → 导出。图片会被复制并重命名为 `im_%06d`，
   COCO 的 image/annotation/category ID 全部重排，同名类别跨批次合并到同一个 ID。

导出后**不会**自动切换训练路径，也**不会**自动授权。要用于正式训练，还需到
「数据集登记」页人工审核并登记（见 `docs/DATASET_REGISTRATION_UI_CN.md`）。

## 完整性保障

- **重复图片内容**：按 sha256 判定，加载时发现重复直接报错，避免同一张图跨组泄漏。
- **图片与 COCO 不一致**：加载时校验 `width/height` 与实际图片尺寸是否一致。
- **加载后被改动**：导出前重新校验每个源 COCO 的 sha256；复制后逐张校验图片 sha256。
- **不覆盖**：输出目录必须不存在，且不能位于任何输入 COCO 目录内部。
- **原子性**：先写临时目录，最后 `os.replace` 整体就位；中途失败不留半成品。

## 场景组只是提示，不是强制

`group` 字段**不会阻止**同一场景组同时出现在 train 和 val。原因是它默认取源目录名
（加载标准数据集时，组名就是 `train`/`val`/`test`），默认状态下跨组是正常的，硬性
拦截会让人无法正常使用。

因此系统采取**提示而非阻断**：
- 分组统计栏会常驻显示 `⚠ 同时出现在 Train 和 Val 的场景组：...`
- 导出结果里会再提示一次

看到这个提示时请自己判断：如果组名还是默认的目录名，可以忽略；如果是你手工命名的
场景组（例如 `书架A_上排`），那就说明真的存在同场景泄漏，应该把它们收拢到同一边。

需要程序化检查时用 `core.manual_dataset_split.split_spanning_groups(state)`，
返回 `{组名: [出现的 split]}`。

## 固定名单与复现

导出目录里的 `manual_split.json` 记录了每张图的 key、sha256、split、group。
用「恢复名单」可以把同一批源数据恢复成当时的划分——前提是**先加载完全相同的来源**，
且图片和标注都没变过（sha256 会被校验）。

恢复是**按图片内容（sha256）匹配**的，不看路径，所以把源数据移到别的目录、别的机器上
之后旧名单依然可用。名单里的 `key` 形如 `<COCO 绝对路径>::<image_id>`，只是当次会话的
句柄，恢复时不参与匹配。文件格式没变，早先导出的名单同样能按新规则恢复。

仍然会被拒绝的情况（这些是有意的完整性检查）：
- 加载的图片集合与名单不是同一批（报「请加载与名单完全相同的源数据」）
- 标注内容变了（`source_sha256` 不符）
- 名单试图改变某张图的 Test 身份

## 已知行为

- 加载后图片文件被移动或删除时，画廊会在该位置显示一张「读取失败」占位图，
  不会让整页崩掉；但该记录仍在状态里，导出时会因 sha256 校验失败而报错。
- 筛选框**按回车应用**（也可以点「刷新 / 跳页」）。每次重绘要生成 24 张带标注的缩略图，
  逐字符触发会很卡，所以只有「显示分组」下拉框是即时生效的。
