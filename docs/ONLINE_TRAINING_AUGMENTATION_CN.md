# SAM3 在线训练数据增强使用说明

## 在哪里设置

1. 启动 UI：`conda run -n sam301 python app.py`。
2. 打开“训练预检”页并填写 train/val、prompt、checkpoint 和训练参数。
3. 在“在线训练数据增强”中选择预设。
4. 重新运行训练预检。确认结果中的 `online_augmentation` 后再启动训练。

## 三种预设

- **关闭**：不增加任何在线变换，每张源图每个 epoch 使用一次。原有基础 YAML 的随机 resize 和 pad 仍会执行。
- **轻量**：使用固定的保守参数。仿射概率 0.5，旋转 -8 至 +8 度，缩放 0.9 至 1.1，最大平移 0.05，水平翻转概率 0.5，颜色抖动概率 0.3/强度 0.15，运动模糊概率 0.1，repeat factor 为 1。
- **自定义**：解锁全部滑块，可自行设置每张源图每个 epoch 的样本数、旋转、缩放、平移和各类概率。

建议先用“轻量”完成一次训练和验证；只有数据量很少或验证结果表明确有必要时，再提高 repeat factor 或变换范围。

## 参数含义

- **每张源图每 epoch 的样本数**：输入大于等于 1 的整数，没有固定业务上限。值为 25 表示每个 epoch 从同一张源图读取 25 次，每次独立随机增强。每个 epoch 的总样本数等于源图数量乘以该值；数值越大会按比例增加训练时间。它不会在数据文件夹中生成新图片。
- **仿射变换概率**：执行旋转、缩放和平移组合的概率。
- **最小/最大旋转角度**：范围 -180 至 180 度，最小值必须不大于最大值。
- **最小/最大缩放倍数**：范围 0.5 至 2.0，最小值必须不大于最大值。
- **最大平移比例**：范围 0 至 0.5，表示图像宽高可平移的最大比例。
- **水平翻转、颜色抖动、运动模糊概率**：范围 0 至 1。
- **颜色抖动强度**：范围 0 至 0.5，同时控制亮度、对比度、饱和度和色相扰动。

## Mask 与数据范围

几何变换对图片和实例 mask 使用同一组随机参数；mask 使用 nearest-neighbor 插值，变换后重新从 mask 计算 bbox 和 area。变换后会自动丢弃退化的极薄目标框（宽或高不足图像边长 0.5% 的目标），避免旋转/平移把 mask 压成 1-2 像素的碎片后，其归一化后近似零面积的框让 Hungarian matcher 的 GIoU 出现除零（`matrix contains invalid numeric entries` 崩溃）。真实书脊即使很细也远大于该阈值，不会被误删。在线增强只作用于 train，val、test 和推理不使用这些随机变换。

本功能不包含随机裁剪、噪声、cutout 或 mixup，避免改变已人工审核目标的语义或把目标裁掉。训练预检会拒绝越界或 min/max 颠倒的参数。

## 暂停与恢复

增强参数写入该 run 的 `runtime_config.yaml`、`dataset_info.json` 和 `training_config_summary.json`。暂停后从 checkpoint 恢复时继续使用同一份 runtime YAML，因此不能在恢复过程中更改增强参数。需要不同参数时，请重新预检并创建新 run。

## 查看记录

每个 run 可在以下文件查看最终参数：

- `config/runtime_config.yaml`：实际 Hydra 变换和数据集配置。
- `dataset_info.json`：数据路径及 `online_augmentation`。
- `training_config_summary.json`：启动前的最终训练参数。
- `training_summary.json`：训练进程结束或暂停后的增强参数和尝试记录。
