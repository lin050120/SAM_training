# SAM3 オンライン学習データ拡張 使用ガイド

## 設定場所

1. `conda run -n sam301 python app.py` で UI を起動します。
2. 「学習プリフライト」を開き、train/val、prompt、checkpoint、学習パラメータを入力します。
3. 「オンライン学習データ拡張」でプリセットを選びます。
4. 学習プリフライトを再実行し、結果の `online_augmentation` を確認してから学習を開始します。

## 3 種類のプリセット

- **オフ**：オンライン変換を追加せず、元画像を epoch ごとに 1 回使います。ベース YAML に元からあるランダム resize と pad は引き続き実行されます。
- **軽量**：固定された保守的な設定です。アフィン確率 0.5、回転 -8～+8 度、スケール 0.9～1.1、最大平行移動 0.05、水平反転確率 0.5、カラージッター確率 0.3/強度 0.15、モーションブラー確率 0.1、repeat factor 1 です。
- **カスタム**：元画像ごとのサンプル数、回転、スケール、平行移動、各変換の確率を範囲内で編集できます。

まず「軽量」で 1 回の学習と validation を完了してください。データが少ない場合、または validation 結果から必要性が確認できた場合にのみ repeat factor や変換範囲を広げます。

## パラメータ

- **元画像 1 枚あたりの epoch ごとのサンプル数**：1～10。3 にすると、各 epoch で同じ元画像を 3 回読み、毎回独立したランダム拡張を適用します。ディスク上に画像ファイルは生成しません。
- **アフィン変換の確率**：回転、スケール、平行移動をまとめて適用する確率です。
- **最小/最大回転角度**：-180～180 度。最小値は最大値以下にします。
- **最小/最大スケール倍率**：0.5～2.0。最小値は最大値以下にします。
- **最大平行移動比率**：0～0.5。画像の幅と高さに対する最大移動比率です。
- **水平反転、カラージッター、モーションブラーの確率**：0～1。
- **カラージッターの強度**：0～0.5。明るさ、コントラスト、彩度、色相の変化量を制御します。

## Mask と適用範囲

幾何変換では画像と全インスタンス mask に同じランダムパラメータを使います。mask は nearest-neighbor で補間し、変換後の mask から bbox と area を再計算します。オンライン拡張は train のみに適用され、val、test、推論には適用されません。

人手レビュー済みターゲットの意味を変えたり切り落としたりしないよう、ランダム crop、noise、cutout、mixup は含めていません。範囲外の値や min/max の逆転はプリフライトで拒否されます。

## 一時停止と再開

最終設定は run の `runtime_config.yaml`、`dataset_info.json`、`training_config_summary.json` に保存されます。再開時は同じ runtime YAML を使うため、同じ run の途中で拡張設定を変更することはできません。別設定を使う場合は、新しいプリフライトと run を作成します。

## 記録の確認

- `config/runtime_config.yaml`：実際の Hydra 変換とデータセット設定。
- `dataset_info.json`：データパスと `online_augmentation`。
- `training_config_summary.json`：起動前の最終学習設定。
- `training_summary.json`：完了または一時停止後の拡張設定とプロセス試行履歴。
